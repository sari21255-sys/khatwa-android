# خطوة — نظرة عامة
تطبيق عربي (RTL) لتتبّع التمارين والتغذية والوزن والنوم، مع ثقافة رياضية ومنهج بأسئلة، وقاعدة أجهزة (869 جهازًا)، ودليل أندية، ومجتمع اختياري.

| المكوّن | التقنية | الحالة |
|---|---|---|
| التطبيق | JavaScript خام في ملف HTML واحد (يُبنى من `fitness-tracker.html` بـ`build.py`) | يعمل، 39 شاشة مختبرة |
| الويب | PWA (service worker، manifest) | جاهز للاستضافة الثابتة |
| الأندرويد | Capacitor 7 (مستودع `khatwa-android`) + بديل TWA | البناء عبر GitHub Actions |
| الحسابات والمجتمع | Supabase (Auth + Postgres + RLS) | المخطط جاهز ومختبر محليًا، المشروع لم يُنشأ بعد |
| الذكاء الاصطناعي والمزامنة | Cloudflare Worker + KV | الكود جاهز ومختبر، غير منشور |

## الملفات
- `fitness-tracker.html`: مصدر الحقيقة للتطبيق. `build.py` ينتج `khatwa.html` و`pwa/index.html` و`www/index.html` للأندرويد.
- `pwa/eq-db.js`: قاعدة الأجهزة وصورها (2MB)، تُحمَّل عند فتح القسم فقط.
- `pwa/worker/`: الوسيط. `supabase/schema.sql`: المخطط. `tests/`: الاختبارات.
- `docs/`: هذه الوثائق.

## الملكية
كل الشيفرة في مستودعك. الخدمات الخارجية: Supabase وCloudflare وAnthropic وGitHub، وكلها قابلة للاستبدال لأن البيانات محلية أولًا ولها تصدير واستيراد.
