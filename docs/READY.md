# الإعدادات، الملف، الطقس والصلاة، «جهّز تمرينك»، مركز الإشعارات

الكود: `app/ready.src.js` + `app/ready.css` (يُحقنان بـ `tools/inject_tracks.py`). الاختبار: `tests/ready.e2e.js` (96 فحصًا عند 320 و390).

## خريطة الصفحات
- الإعدادات: بطاقة (اسم أو «ضيف»، الرياضات، «ملفي الشخصي»، حالة الحفظ) + ست مجموعات قابلة للطي بقيمتها بجانب الاسم + «إعدادات سابقة» (الهدف، الاستيراد، النسخ، الحساب، المزامنة، الربط الصحي) محفوظة كاملة.
- ملفي الشخصي (`S.sub='pf'`): اسم وصورة، رياضات وأهداف، جدول، أماكن، قياسات، ربط صحي، تفضيلات قبل التمرين.
- مركز الإشعارات: الوارد / التحكّم (مفتاح عام، أربع فئات، ساعات هدوء، صامت، «لدي مشكلة»: اختبار وإذن).
- اليوم: بطاقة المدينة والساعة والطقس والتفاصيل ومواقيت الصلاة. صفحة المسار والحصة المجدولة: بطاقة «جهّز تمرينك» + «قارن أوقات التمرين».

## البنية
واجهات قابلة للاستبدال: `WXP` (الطقس)، `WXA` (التحذيرات الرسمية، لا مزوّد في هذا البناء)، `NTS` (مجدول الإشعارات)، `window.__now` (ساعة الاختبار). الصلاة تُحسب محليًا (`rdTimes`) وتُسمّى «مواقيت محسوبة». التخزين: `S.sj.set`، `S.sj.wx`.

## قواعد النصائح (المعرّف ← المصدر ← الشرط)
| القاعدة | المصدر | الشرط |
|---|---|---|
| official | تنبيه رسمي من المزوّد | وجود تنبيه يتقاطع مع الفترة |
| lightning | NWS lightning-sports | رمز طقس ≥ 95 (توقع لا تحذير) |
| swim-nowarn | غياب مصدر | سباحة خارجية بلا مصدر تحذيرات |
| heat-high / heat-mid | CDC التمرين في الحر | محسوسة ≥ 38 / 32 |
| cold | قاعدة عامة | محسوسة ≤ 10 |
| uv | WHO | مؤشر ≥ 6 |
| dark | قاعدة عامة | الحصة بعد الغروب أو قبل الشروق |
| rain / wind | قاعدة عامة | احتمال ≥ 50% / هبّات ≥ 45 |
| water | CDC | دائمًا، بلا كمية موحّدة |
| air | غياب بيانات | جودة الهواء غير متاحة |

## ما ثبت وما لم يثبت
مثبت بالاختبار الآلي (محاكاة): المواقيت ونطاقها، المجموعات، مدينة بلا إذن موقع، حرارة+غروب+صلاة، برق السباحة، تنبيه رسمي، حديد داخلي، توقع قديم/منتهٍ، تغيير المدينة والمنطقة الزمنية، معرّفات ثابتة وعدم التكرار، النقل والإلغاء، ساعات الهدوء، المفتاح العام، فاصل الصلاة أثناء الجلسة، تبديل المظاهر الستة دون فقد المجموعات.

**غير مثبت / يحتاج تحققًا قبل النشر:**
- Open-Meteo: لم يُختبر الاتصال الحي من هنا (لا شبكة)؛ الشروط التجارية والنسب تحتاج مراجعة قبل النشر التجاري. أُضيف `api.open-meteo.com` إلى CSP.
- أم القرى: لم تُطابَق بجدول محلي موثوق؛ الافتراضي رابطة العالم الإسلامي.
- التحذيرات الرسمية (NCM) وجودة الهواء والمياه: لا تكامل.
- الإشعارات على Android الفعلي (الإذن، قنوات صامتة، التنبيه الدقيق، إعادة التشغيل): لم تُجرَّب؛ المجدول يعمل عبر LocalNotifications ومُحاكى في الاختبار.
- «استخدم موقعي» عبر WebView يحتاج إذن `ACCESS_COARSE_LOCATION` في بناء Android (مجلد android غير موجود في المستودع).
- الإنجليزية: النصوص الجديدة ليست مترجمة بالكامل (مفاتيح ENT الأساسية فقط). لم يُختبر 320/390 بالإنجليزية.
- إفصاحات الخصوصية وPlay Data Safety لم تُحدَّث (إرسال إحداثيات المدينة إلى مزوّد الطقس).
