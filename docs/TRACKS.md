# المسارات الرياضية الخمسة — SIJIL

الفرع: `ux/sijil-identity`. الكود: `app/tracks.src.js` + `app/tracks.css` يُحقنان بـ `tools/inject_tracks.py` قبل أول `render()`.

## خريطة الصفحات
- التمرين (مركز): الحديد · الجري · السباحة · الكالسثينكس · التدريب الوظيفي + لافتة جلسة جارية + بطاقة تعارض.
- كل مسار (غير الحديد): نظرة عامة / الخطط / المكتبة / السجل والتقدّم.
- الجري → «النشاط والخطوات» (الكارديو القديم). الحديد → «الديدلفت» (`UI.trk='dl'`).
- شاشة الجلسة الحيّة والملخّص: تخفي الشريط السفلي والترويسة.
- اليوم: حصص اليوم المخططة + استئناف. التقدّم: السجل الموحّد بفلتر. «+»: تسجيل تمرين (اختيار مسار، جلسة أو نشاط سابق).

## نموذج البيانات (`S.sj`، مفتاح جديد؛ `S.sx` للحديد لم يتغيّر)
`{ss:[جلسة], tw:{يوم:[{k,t}]}, cal:{مهارة:{i,h}}, cfg:{run,swim,cali}, ft:[قوالب وظيفية]}`
جلسة: `{id,k,st:act|pau|done,day,t0,t1,acc,ra,plan:{id,n,ver,…},d:{…},res:{…},src,man?,par?}`
الزمن النشط = `acc + (ra ? now−ra : 0)` (من الطوابع، يصمد أمام إعادة التحميل والإغلاق).
الترقية: `SJ()` ينشئ الحقول الناقصة؛ النسخ القديمة بلا `S.sj` تعمل دون تحويل. النسخ الاحتياطية تحمل `S.sj` تلقائيًا (المفاتيح غير المعروفة لا تُحذف).

## جاهزية كل مسار
- **الحديد:** جاهز (لم يتغيّر) + صفحة الديدلفت.
- **الجري:** يدوي جاهز (زمن، مسافة، لفّات، قوالب مشي/جري، فواصل، 5 كم). GPS والاستيراد **غير منفذين**؛ يلزم جهاز Android لاختبار الإذن وقفل الشاشة.
- **السباحة:** جاهز يدويًا (مسبح/مفتوحة، أطوال، SWOLF بشرط وجود زمن وضربات). لا استيراد ساعات.
- **الكالسثينكس:** جاهز (4 مهارات بخرائط مراحل، بدائل، ثبات/تكرار). المراحل تُرقّى بقرارك.
- **الوظيفي:** جاهز (AMRAP/EMOM/For Time/جولات ثابتة، منشئ حصص، إصدارات، مقارنة بفئة مطابقة). صفّارات صوتية/اهتزاز غير منفذة.

## غير منجز / غير مختبر
مزامنة `S.sj` عبر Postgres (لم تُختبر، تحتاج PSQL)، جهاز Android فعلي، الإشعارات الخلفية للمؤقت، GPS، Health Connect، تحويل الوحدات الكامل في الواجهة الإنجليزية، فحص إمكانية الوصول بقارئ شاشة.
