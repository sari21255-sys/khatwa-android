# 08 — تجربة المستخدم والواجهة

**الهوية البصرية تبقى كما هي:** أبيض/أسود مع أيقونات ملوّنة ذات معنى، صناديق صغيرة معنونة، أشرطة أيقونات، أشرطة داكنة للوجبات، قوائم ثقافية تنفتح في مكانها.

## نتائج مُقاسة
- الاتجاه واللغة وviewport صحيحة، والتكبير غير محجوب (T21a).
- 0 من 216 زرًّا بلا اسم؛ 0 صور بلا alt؛ 0 حقول بلا تسمية (T21b/d).
- 4 أهداف لمس أصغر من 32px (T21c).
- فيض أفقي 5px عند 320px فقط (T20-320)، لقطة: `evidence/shot-320-dash.png`.
- الرسم 11 ms مع بيانات سنتين.
- الوضع الإنجليزي: ≈258 حرفًا عربيًا باقية في الرئيسية (نصوص طويلة بقيت عربية عمدًا).

## ملاحظات غير مقاسة (حكم تصميمي، قابل للنقاش)
| الملاحظة | الأولوية |
|---|---|
| `render()` الكامل يفقد التركيز ومكان التمرير عند كل تغيير؛ يضر لوحة المفاتيح وقارئات الشاشة | متوسطة |
| 39 شاشة والتنقل متعدد المستويات: يلزم قياس مهمة «سجّل تمرينًا» بعدد النقرات | متوسطة |
| عدم وجود حالة فارغة/أخطاء موحّدة للمجتمع عند غياب Supabase (`config.js` فارغ) | عالية قبل النشر |
| لا زر «مسح بياناتي» ولا «حذف نسخة المزامنة» | عالية (خصوصية) |
| تباين الألوان لم يُقَس بأداة | منخفضة |
| ما لم يُراجع: وضع الخط الكبير للنظام، قارئ الشاشة TalkBack على جهاز | — |

## توصيات
1. إصلاح الصف العلوي عند 320px، ورفع الأهداف الصغيرة إلى 44px.
2. إعادة رسم موضعية للأقسام الكبيرة أو حفظ/استعادة التركيز.
3. شاشة «بياناتي والخصوصية»: تصدير، مسح محلي، حذف المزامنة، حذف الحساب، إدارة الموافقات (ذكاء/Health Connect).
4. إكمال الترجمة الإنجليزية للنصوص الطويلة أو إعلانها صراحة.
