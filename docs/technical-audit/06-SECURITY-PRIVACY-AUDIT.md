# 06 — الأمان والخصوصية

منهج OWASP (Top 10 / ASVS مستوى 1) عبر قراءة الكود والاختبارات أعلاه. **لم يُجرَ اختبار اختراق** ولا يُدَّعى.

## مقارنة سياسة الخصوصية بالكود
| الادعاء | الواقع | الحكم |
|---|---|---|
| «لا يكتب التطبيق شيئًا إلى Health Connect» | manifest يطلب WRITE_STEPS/DISTANCE/ACTIVE_CALORIES/HEART_RATE/WEIGHT | **متناقض** |
| يقرأ: خطوات، سعرات، مسافة، نبض، نوم | manifest يزيد READ_WEIGHT | **ناقص** |
| «لا نحتفظ بالصور بعد المعالجة» | الوسيط لا يخزن الصور في الكود المقروء؛ لم يُتحقق من سجلات Cloudflare | مدعوم جزئيًا |
| «بيانات الجهاز تُحذف بمسح البيانات» | صحيح للنظام؛ لا زر داخل التطبيق | صحيح لكن ناقص UX |
| «حذف الحساب من الإعدادات» | `delete_my_account()` مختبرة في SQL؛ الواجهة غير مختبرة | غير مؤكد |
| «نسخة المزامنة: راسلنا لحذفها» | لا نقطة DELETE في الوسيط | يخالف متطلب Play (رابط حذف ويب + مسار داخل التطبيق) إن وُجد إنشاء حساب |
| «لا أدوات تتبع إعلانية» | لم أجد SDK إعلانات في الكود | مدعوم |
| «التذكيرات محلية» | `natSched` محلي | مدعوم |
| بريد التواصل | يُحقن من `config.js` وهو فارغ | **حالة فارغة الآن** |

## OWASP Mobile/Web — حالة سريعة
M1 إساءة أذونات: فشل · M2 سلسلة التوريد: لم يُفحص · M8 إعدادات أمنية خاطئة: فشل (debuggable/backup) · M9 تخزين غير آمن: localStorage غير مشفّر (مقبول لتطبيق ويب؛ يوصى بتقليل المخاطر على أندرويد) · A05 Security Misconfiguration: فشل (ترويسات) · A07 Identification: ضعف (رمز دائم).
