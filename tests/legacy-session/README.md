# اختبارات المسار القديم (حصة جارية)

هذه الاختبارات كُتبت لتجربة «ابدأ الحصة ← مشغّل ← إنهاء» التي أُلغيت في أمر السجل السريع.
أغلب إخفاقاتها نقرٌ على أزرار محذوفة (`wkstart`, `wkty`, `runst`, `qatog`, `#wk-w`) لا تراجعاتٌ في الميزات.
حلّت محلّها `tests/quicklog.e2e.js` (التسجيل المباشر، الخطتان، الأنواع الخمسة، الألبوم، التغذية، المشهد، الترقية).
بقيت هنا مرجعًا؛ ولا تُشغَّل ضمن `run-all.sh`. أي فحص منها ما زال مطلوبًا (تباين السمات، التفاف 320، خط Almarai) يُنقل إلى quicklog.e2e.js.
